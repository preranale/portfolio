AI systems · thoughtful engineering

I started with a B.Tech in Biotechnology — a discipline that wired me to think in systems, run controlled experiments, and never trust a result I haven't stress-tested. That instinct transferred perfectly into software engineering.

"If you can't explain the data pipeline end-to-end, you don't own the model."

At 4 Systems Info Solutions I spent over two years building at real scale — Spring Boot APIs processing millions of records, database schemas tuned to shave 40% off query latency, and CI/CD pipelines that cut release windows by 60%. Real systems, real traffic, real accountability.

Now at Arizona State University (GPA 4.0), I've gone deeper into intelligence: embedding 83,000+ FDA documents for RAG retrieval, architecting a 7-service ML pipeline that retrains itself from live user feedback, and writing a LangGraph agent that detects, diagnoses, and patches its own bugs.

I also taught 150+ students Java as an Instructional Assistant — because the clearest proof you understand something is your ability to explain it to someone who doesn't.
