001

Data Flywheel Pipeline

Question
Can a recommender retrain and promote itself without ever shipping a worse model?
Method
User feedback streams through Redis Streams. At 50+ events, retraining starts on its own. An SVD matrix factorization model, trained on 100k MovieLens ratings, must pass two gates before promotion: RMSE of 0.947 or better, and 100% catalog coverage.
Apparatus
7 services in Docker Compose: Inference, Feedback, Feature Pipeline, Scheduler, Trainer, Redis, MLflow. FastAPI, React, pytest.
Result
Models hot-swap into production with no downtime, and no model-promotion step is manual.

002

MedCareBot

Question
Can a health chatbot stay grounded in drug data, and stay up when a model provider fails?
Method
83,843 FDA drug records are embedded and indexed in ChromaDB. Relevant chunks are retrieved at query time and passed to GPT-4o-mini to generate grounded answers. LLM-generated knowledge checks test whether users understood.
Safeguards
A 3-layer safety system (intent filter, prompt filter, response filter) and automatic fallback from OpenAI to Gemini 1.5 Flash.
Conditions
Capstone for industry sponsor MyEdMaster: 6 engineers, 6 Agile sprints. React, Django, PostgreSQL, AWS Cognito.
Result
136 automated tests (85 Vitest, 51 pytest); the suite caught 3 critical retrieval bugs before user acceptance testing.

Self-Healing CI/CD Agent

Question
What if a failing build could diagnose and repair itself?
Method
A LangGraph agent, powered by a Groq-hosted LLM, detects failing tests, reasons about the root cause, patches the code and reruns CI.
Result
The detect, diagnose, patch, rerun loop runs without human intervention.
